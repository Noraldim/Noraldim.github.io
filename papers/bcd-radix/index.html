From Decimal Digits to Binary Bits: Radix Conversion in C, IA-32 and x86-64

Read the paperDownload PDFSource codeLive demo

What it is about

Every number a person types is decimal, and every number a processor stores is binary. The boundary between the two is where bugs like 0.1 + 0.2 != 0.3 come from. This paper takes the BM_Architecture course project, which converts BCD-style decimal inputs such as 532.13022 into binary, and follows it from the mathematics to the machine code to the browser.

What the paper covers

  • The two classical algorithms, repeated division for the integer part and repeated doubling for the fraction, formalised with proofs of correctness, termination and the truncation-error bound ε < 2−n.
  • A line-by-line walk through the C implementation.
  • The machine code GCC 12.2 produces for both targets: IA-32’s stack-based x87 FPU and cdecl calling convention versus the SSE2 register file and System V AMD64 ABI of x86-64. Every compiler idiom is explained.
  • The HTML/JavaScript front-end: a BCD number generator, and a 16-bit sign-magnitude binary calculator whose loop length depends on the unit in the last place of an IEEE-754 double.
  • An experimental evaluation, six robustness defects (negative inputs, int overflow, malformed input and more), and an exact, integer-only conversion routine that removes all floating-point error.
